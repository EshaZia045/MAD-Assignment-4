# React Native Maps with Expo Location

## Project Title
User Location Tracking using Expo Location and React Native Maps

---

# Objective

The purpose of this project is to:
- Get the current location of the user
- Display the location on Google Maps
- Explore React Native Maps components
- Use Marker, Circle, Geofencing, and Callout components

---

# Technologies Used

- React Native
- Expo
- Expo Location
- React Native Maps

---

# Packages Used

Install required packages using:

```bash
npx expo install expo-location
npm install react-native-maps
